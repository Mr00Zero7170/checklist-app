# Checklist App

A minimal offline-first PWA for tracking daily habits. Install it on your phone, check things off, build streaks. That's it.

## The Why

I built this because I kept losing momentum on things that mattered to me. Not because the tasks were hard—because I couldn't *see* the streak. Consistency is invisible until you visualize it.

Most habit apps are bloated. They want notifications, data, subscriptions. I just wanted something that lived on my phone, worked offline, and kept score. So I built it.

## What You Get

- **Offline first** — No internet? Works perfectly.
- **Installs like an app** — Runs full screen on Android. Feels native.
- **Your data stays yours** — Everything lives on your phone. No accounts, no servers, no tracking.
- **Fast** — No frameworks, no bloat. Just vanilla JS and a service worker.
- **Minimal** — It does one thing well.

## Deploy Your Own (5 Minutes)

1. Fork this repo or use it as a template
2. Enable GitHub Pages (Settings → Pages → Deploy from branch)
3. Done. Your app is live at your own URL.

## Install on Your Phone

1. Open the link in Chrome on Android
2. Tap the menu (⋮) → **Install app**
3. Open from home screen

Everything you check off gets saved. Offline or online, it doesn't matter.

## Made With

- Vanilla JavaScript (no frameworks)
- Service Workers (offline support)
- Web App Manifest (installable)
- Local Storage (data on your device)

## The Real Talk

This isn't revolutionary. It's just useful. I use it every day. If you're like me—wanting to track habits without all the noise—give it a shot.

Customize it however you want. Make it yours.
